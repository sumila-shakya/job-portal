# Job Portal

A Job Portal API built with Node.js, TypeScript, and Express. The system allows users to register, search for jobs, apply for jobs and post job listings.

## 🛠️ Tech Stack

**Backend:**
- Node.js 20+
- TypeScript
- Express.js

**Databases:**
- MySQL 8.0
- MongoDB 8.0+

**Libraries:**
- Drizzle ORM (MySQL)
- Mongoose (MongoDB)
- Zod (Validation)
- JWT (Authentication)
- Bcrypt (Password hashing)
- Multer (File upload)
